# code-measurements

One-off measurements of public code and the claims made about it. Raw data committed,
method stated in each folder, and the answers that turned out wrong kept visible rather
than deleted.

Companion to [solana-measurements](https://github.com/madaearly/solana-measurements),
which covers on-chain work. This repository covers repositories, packages and registries.

| folder | question | date |
|---|---|---|
| [jev-2026-09](jev-2026-09) | Ten repos were listed as "complete Jev blueprints". How much of each one is actually Jev? | 2026-09-22 |

Every folder runs offline from committed data, or from a `git clone` and nothing else.
No API keys.
